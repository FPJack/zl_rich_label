# zl_rich_label example

Demo app of [zl_rich_label](https://pub.dev/packages/zl_rich_label), a port of the iOS
ZLRichLabel example:

* **ZLRichLabel Demo** (home): `ZLTagRichLabel` / `ZLRichLabel` cases 1 – 31 — tag styles and
  taps, press highlights, error tolerance, inline widgets, Arabic RTL, custom rules, rule
  priorities, inline widget resizing, dark mode / text scale, render cache statistics,
  expand / collapse, long press / double tap, selection & copy, generic tags, capsules and
  gradients, padding, inline widgets following the label width, `ZLTextStyle` chains.
* **ListView**: the same cards in a lazily built `ListView`.
* **声明式**: declarative usage (the SwiftUI page of the iOS example).
* **Base**: the low-level `ZLAttributedLabel`, cases 1 – 14.
